# Geography Gym: working notes

- Static site, no build step. Everything served is in `public/` (`index.html`, `styles.css`, `app.js`, `data/`, `fonts/`).
- Deployed by Cloudflare Pages from the `main` branch (output directory `public`, no build command). A push to `main` goes live.
- **After every change: commit and push to `main`**, unless the user asks to hold off or to use a branch.
- Topics are defined in the `TOPICS` array at the top of `public/app.js`: flags, capitals, state-flags and state-capitals. They all share one engine (practice, quiz, name them all, browse). Each topic's progress lives under the `geography-gym-<topic>-v1` localStorage key, and shared settings live under `geography-gym-settings`. URLs look like `#<topic>-<mode>`, for example `#state-capitals-quiz`.
- The state flags come from region-flags (2022), except MN, UT and MS, which come from us-state-flags because they changed after 2022. If another state adopts a new flag, add it to `NEWER` in `scripts/build-data.mjs`.
- Design direction: "Clean". One centered column, and the flag is the only loud element. A single menu at the top right (its label is the current topic name) holds the topic picker, the modes and the settings, next to a light/dark toggle. Don't add new menus, sidebars or tab bars; put new options in that menu.
- Colors live in CSS variables at the top of `styles.css`, with a `[data-theme="dark"]` block. Style everything through those variables.
- `public/data/*.json` is generated by `npm run data` (scripts/build-data.mjs). Don't edit it by hand.
- To test locally, run `npm run dev` and open http://localhost:8080.
