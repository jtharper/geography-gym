# Geography Gym: working notes

- Static site, no build step. Everything served is in `public/` (`index.html`, `styles.css`, `app.js`, `data/`, `fonts/`).
- Deployed by Cloudflare Pages from the `main` branch (output directory `public`, no build command). A push to `main` goes live.
- **After every change: commit and push to `main`**, unless the user asks to hold off or to use a branch.
- Geography Gym will grow beyond flags (capitals, state flags, lakes…). Country flags is the first topic, and its progress is stored under the `geography-gym-flags-v1` localStorage key. Give each new topic its own key.
- Design direction: "Clean". One centered column, and the flag is the only loud element. A single "Practice ⌄" menu at the top right holds the modes and settings, next to a light/dark toggle. Don't add new menus, sidebars or tab bars; put new options in that menu.
- Colors live in CSS variables at the top of `styles.css`, with a `[data-theme="dark"]` block. Style everything through those variables.
- `public/data/*.json` is generated by `npm run data` (scripts/build-data.mjs). Don't edit it by hand.
- To test locally, run `npm run dev` and open http://localhost:8080.
